# Phone screens

The offline picker opens independent game sessions. Saved-session choice is inside each game for later setup or a game, with resume, saved date/time and confirmed replacement. Every game's first settings page is temporary and opens directly; old snapshots containing only that page are removed without a chooser. Returning or resetting to the first page removes saved setup, with retry on storage failure. Header Home saves/leaves durable progress or first covers an active game; native Back is handled by the game before route navigation.

Who What Where: settings → per-team roster → review → named handoff → timed turn → word recap → round standings where appropriate → results. The paused cover hides words and preserves time. Roster setup and scored turns persist independently of component lifetime.

Hat: settings → per-team roster → review → private figure entry for every player → named handoff → timed turn → recap → next team/results. Describe, One Word and Charades are phases of the same shared deck; a phase may change during a turn without restarting the clock.

Imposter: settings → roster → review → individual concealed/revealed roles → twice-around clues → discussion → final-reveal confirmation → results. Background/Back covers private roles; returning re-reveals the same player's assigned role. Voting happens socially; there is no in-app vote, elimination or timer.

GameShell supplies compact header, safe-area body and fixed footer. DeviceTeamSetup/Review supply shared roster presentation; each game binds its own mutations. Device controllers own persistence and rules; React pages own dialogs and presentation only. Lucide is the standard control icon set; custom SVG identities distinguish games.

Aim for one screen at default phone text size; preserve scroll access with keyboard, large text or long content rather than shrinking controls. Live word columns scroll internally with +N others cues. No duplicate instructional prose, no player names inside compact numbered team cards, no layout shift when hints reveal.

Aesthetic demos are isolated under docs/design/aesthetic-demos and are not runtime screen specifications.

WWW, Imposter and Trivia difficulty controls show three buttons: Easy, Medium and Hard, with Hard selected for new setups. Easy uses easy content only, Medium mixes easy/medium equally and Hard mixes all three tiers equally. App Settings offers Simple mode, which restricts new automatic selection to easy content regardless of a game's difficulty choice. Shortage filling stays within allowed tiers and selected categories, including the easy-only limit while Simple is on. It changes difficulty, not audience suitability; manual Hat clues and existing selected/dealt content are preserved.

Trivia (always visible on the picker): cooperative setup → questions → answer reveal and Correct/Incorrect marking → shared score and scrollable question recap. Setup places headings above question-count, difficulty, category and reveal controls. Counts are 10, 20 or 30 only. Categories use eight toggle buttons with pressed states plus a ninth Select all/Clear all action in a three-column grid. Start quiz stays in the fixed footer. There is no available-question count: too little eligible content shows “Not enough questions match these settings. Choose fewer questions or broaden your selection.” An empty category selection shows “Choose at least one category.” Both prevent starting. Setup edits remain temporary until Start quiz commits the quiz.

Trivia has no teams. Reveal after each question has no writing. Reveal at the end always shows an optional Your answer field while answering, followed by a persisted Ready for the answers? screen. Go to answers begins review; an exact canonical-answer or acceptable-alias match after trimming, lowercasing and collapsing whitespace is automatically marked Correct on reveal. Other answers need a manual mark. Incorrect sits on the left in red and Correct on the right in green, using mark colours separate from the primary action colour. Players can override either mark, and Next/Finish quiz stays unavailable until the revealed question is marked. Expired unshown questions are excluded from score and recap. Restore/background returns to the saved quiz chooser. Completed score and recap remain saved until reset; WWW, Hat and Imposter completion instead removes their saved game without storing a synthetic first-page setup. The Show Trivia setting is removed; all four games are always visible on the picker. Long questions and shared answers retain scroll access.
