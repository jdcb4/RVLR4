# Recess material studies

Open index.html. All fonts, styles and scripts are local. Desktop compares three directions side by side; mobile selects one direction at a time. Review-page scrolling is separate from the simulated phone screen.

A uses restrained sticker layers; B uses asymmetric rounded paper and layered shadows; C uses deliberately scissor-cut geometry and tape accents. All show the same representative Who What Where screens. These are design-only illustrations, not production rules, saved sessions or final copy. Other game tiles open explanatory covers. No app files or APKs change.

Use Picker, Handoff, Play and Results to compare; Correct, Skip, returned skipped words, Hint and Pause work independently in each phone. The sample clock starts at handoff/resume. Hints retain their slot height. Motion respects reduced-motion preferences. Local Bricolage font includes its OFL license.

Verified in Chromium at 1440px desktop and 360px mobile: all three play interactions, stable hint layout, pause/resume and no phone horizontal overflow. JavaScript syntax passed. The design scan flagged the explicitly requested cream palette and cut-paper contours; these are intentional. Real Android behavior is outside this mockup.
